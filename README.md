# Alex Coelho Portfolio

Static HTML/CSS/JS portfolio with:
- Light / dark mode toggle
- Glassmorphism UI
- Responsive mobile layout
- Animated reveal effects
- Updated BA + PM resume content
- GitHub Pages deployment workflow

## Free hosting

Create a public GitHub repository named `alexcoelhohere.github.io`, upload these files, then go to Settings → Pages → Source → GitHub Actions. The included workflow deploys the site automatically.

Site URL: https://alexcoelhohere.github.io/
